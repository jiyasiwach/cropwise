# Knowledge base

Every factual claim KrishiMitra makes must come from a file in this folder, and every answer
cites the file it came from. If the question is not covered here, the assistant says so and
refuses rather than improvising — particularly for pesticide and fertiliser doses.

Each document carries a YAML header with its real source and the date it was written down.
Documents marked `needs_verification: true` are the commonly published all-India figures and must
be replaced with cited state-specific guidance from ICAR/KVK publications before any farmer acts
on them.
